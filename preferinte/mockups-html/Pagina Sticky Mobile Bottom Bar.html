.sticky-mobile-bar {
  display: none; /* ascuns pe desktop */
  position: fixed;
  bottom: 0; left: 0; right: 0;

JSDetecție rută activă 
(function() {
  var path = window.location.pathname;
  var routeMap = {
    'home': function(p) { return p === '/' || p === '/acasa/'; },
    'catalog': function(p) { return p.indexOf('/suplimente') === 0; },
    'quiz': function(p) { return p.indexOf('/test-60') === 0; },
    'cart': function(p) { return p.indexOf('/cos') === 0; }
  };
  document.querySelectorAll('.smb-item').forEach(function(item) {
    var route = item.dataset.route;
    if (routeMap[route] && routeMap[route](path)) {
      item.classList.add('active');
    }
  });

  /* Actualizare badge coș dintr-un cart store (localStorage sau global) */
  var count = parseInt(localStorage.getItem('cart_count') || '0', 10);
  var badge = document.querySelector('.smb-badge');
  if (badge) {
    badge.setAttribute('data-count', count);
    badge.textContent = count;
  }
})();
Note implementare
  • Ordine de adăugare pe pagină: nav-ul se pune înainte de </body>, nu în header. CSS-ul de la body { padding-bottom: ... } previne acoperirea conținutului.
  • Cart badge sync: actualizează data-count la fiecare modificare coș (add/remove/clear). Cifra dispare automat când data-count="0" via CSS.
  • Accesibilitate: tap target minim 64×64px (depășește 44pt Apple HIG), aria-label pe nav, focus visible în Tab navigation.
  • iPhone notch: env(safe-area-inset-bottom) rezolvă automat. Testează pe device real (devtools mobile emulator nu redă safe-area corect).
  • Z-index: 100, ca să stea peste orice element din pagină (modale dă-le z-index 1000+).
